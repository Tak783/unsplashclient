Architecture 3 layers

Dependencies run vertically. A package may import only from the layers below it.

Testing Layer
CoreTesting

These two sit beside the ladder rather than on a rung. CoreDesignSystem is imported by Feature UI and by apps, never by a layer that has no screen. CoreTesting is imported only by test targets, never by anything that ships.

Greyed boxes are apps the layers below would already support. Only the iOS app is built today.
